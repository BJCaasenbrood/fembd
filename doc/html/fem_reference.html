Model

  • fembd.Body - elastic or rigid body: mesh, material, K and M
  • fembd.Body.rigidSurface - rigid body from an STL surface (no meshing)
  • fembd.Body.pointMass - rigid body from mass properties only
  • setMass - set a rigid body's mass properties (e.g. from CAD)
  • fembd.Assembly - bodies, connections, supports; reduced K, M and u = T*q
  • fembd.Model - nonlinear multibody model (large rotations)
  • fembd.material - isotropic linear-elastic material

Assembly methods

  • add - add a body
  • tie - bonded tie or elastic interface
  • couple - rigid coupling of nodes to a reference point
  • joint - kinematic joint between reference points
  • transmission - elastic or rigid ratio between joints or bodies (belts, gears)
  • pose - move a joint to a finite position
  • fix - supports
  • dof - global dof indices
  • input - named input (actuator, load)
  • output - named output (sensor)
  • statespace - state-space model with the inputs and outputs
  • ioMatrices - inputs and outputs in the full space
  • qdof - positions of dofs in q
  • system - reduced K, M and T
  • assemble - unconstrained K and M
  • constraints - the map u = T*q
  • plot - plot (deformed) bodies
  • animate - slow-motion mode animation
  • nonlinear - nonlinear model of the assembly
  • Model.simulate - time integration (generalised-alpha)
  • Model.animate - animation of a simulation

Analysis

  • fembd.modes - natural frequencies and mode shapes
  • fembd.craigBampton - Craig-Bampton and Guyan reduction

Meshing and I/O

  • fembd.meshSTL - tetrahedral mesh of an STL with Gmsh
  • fembd.readMsh - read an ASCII Gmsh .msh file
  • fembd.gmsh - run Gmsh
  • fembd.boxSTL, fembd.cylinderSTL - simple test geometry
