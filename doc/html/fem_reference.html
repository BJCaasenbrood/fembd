Bodies

  • fmbd.Body - rigid or elastic body: geometry, material, mass properties
  • fmbd.Body.elastic - elastic body meshed with Gmsh
  • fmbd.Body.rigid - rigid body from an STL surface (no meshing)
  • fmbd.Body.pointMass - rigid body from mass properties only
  • setMass - set a rigid body's mass properties (e.g. from CAD)
  • massProperties - mass, centre of mass and inertia
  • fmbd.material - isotropic linear-elastic material

System: model description

  • fmbd.System - the multibody system
  • add - add a body
  • couple - rigid coupling of nodes to a reference point
  • tie - bonded tie or elastic interface between surfaces
  • joint - kinematic joint, with springs, dampers, Position, Velocity
  • transmission - belt, gear or cable between coordinates
  • fix - supports of reference points, joints and nodes
  • input - named input (actuator, load)
  • output - named output (sensor)
  • update - rebuild after changing a body directly

System: analysis

  • simulate - time integration (generalised-alpha)
  • equilibrium - static equilibrium
  • linearize - linear model about a state
  • statespace - modal state-space model
  • modes - natural frequencies and mode shapes
  • energy - kinetic, gravity, strain and spring energies
  • plot, animate - draw a state, play a simulation
  • plotMode, animateMode - draw or animate a mode shape
  • modeShapes - nodal mode shapes of an elastic body

Utilities

  • fmbd.meshSTL - tetrahedral mesh of an STL with Gmsh
  • fmbd.readMsh - read an ASCII Gmsh .msh file
  • fmbd.gmsh - run Gmsh
  • fmbd.modes, fmbd.craigBampton - modes and reduction of K, M
  • fmbd.boxSTL, fmbd.cylinderSTL - simple test geometry
