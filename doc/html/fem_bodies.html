Bodies, Meshing and Materials

A body is one part of the assembly: a mesh and a material. It can be elastic or rigid.

Creating a body

b = fem.Body(src, mat, Name=Value)

src is an STL file (meshed with Gmsh), an ASCII Gmsh .msh file (version 2.2 or 4.1), or a struct with fields X (n x 3 nodes) and T (ne x 4 or ne x 10 tetrahedra, Gmsh node order).

OptionDefaultDescription
Namefile nameName used to refer to the body in an assembly
Scale1Coordinate factor applied after meshing, e.g. 1e-3 for mm to m
SizeGmsh defaultMaximum element size, in file units
Order22 = quadratic Tet10, 1 = linear Tet4
RemeshtrueRemesh the STL surface (false: keep the STL triangles)
FeatureAngle40Angle (deg) used to split the STL into smooth patches
RigidfalseMake the body rigid (6 dofs at RefPoint)
RefPointcentroidReference point of a rigid body

Element order

Use the default Tet10 elements. Linear Tet4 elements are far too stiff in bending: on a cantilever, Tet4 is still about 9% off on a fine mesh where Tet10 is within 0.2% on a coarse one (see Tutorial 2).

Tet10 edge nodes are placed on the curved surface reconstructed from the STL. If that inverts elements (coarse meshes on small radii), meshSTL remeshes with straight-sided Tet10 and warns; a smaller Size keeps the curved geometry.

Materials

A material is a struct with a 6 x 6 stiffness D in Voigt notation (order xx yy zz yz xz xy, engineering shear strains) and a density rho. fem.material(E, nu, rho) gives an isotropic material; any symmetric positive-definite D works, e.g. orthotropic composites (see Tutorial 3).

mat = fem.material(210e9, 0.3, 7850);
cfrp = struct('D', D, 'rho', 1600);

Mass matrix

b.matrices() returns the body's K and consistent M. With Lumped = true (also in a.system) M is diagonal, using HRZ lumping: each element's mass diagonal is scaled to keep the element mass.

Rigid bodies

With Rigid = true the body has no stiffness and 6 dofs [ux uy uz rx ry rz] at its reference point; all its nodes follow u = u_ref + r x (x - x_ref). The mesh only provides mass, inertia and the surface for ties and plots, so a coarse Tet4 mesh is enough.

Rigid bodies do not need a volume mesh at all:

b = fem.Body.rigidSurface('lid.stl', 7850, Scale = 1e-3);   % STL surface only
b = fem.Body.pointMass(m, c, J, Name = 'motor');            % mass properties only

rigidSurface computes mass, centre of mass and inertia exactly from the closed STL surface. pointMass takes mass m, centre of mass c and inertia tensor J (about c), e.g. from a CAD report; it has no surface and is connected with a joint. See Tutorial 6.

Placing parts

b.transform(R, t) moves a body rigidly, x -> R*x + t.
