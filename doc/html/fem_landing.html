fmbd: Flexible Multibody Dynamics

fmbd models assemblies of STL parts as flexible multibody systems. Rigid parts need only their surface or mass properties; elastic parts are meshed with Gmsh and reduced to a few modes in a moving frame. Parts are connected by joints, couplings, ties, springs, dampers and transmissions. One nonlinear model gives simulations of large motions (with controllers in the loop), equilibria, and linear models about any operating point.

s = fmbd.System(Gravity = [0 0 -9.81]);
s.add(fmbd.Body.rigid('link.stl', 7850, Scale = 1e-3));
s.add(fmbd.Body.elastic('tool.stl', fmbd.material(70e9, 0.33, 2700), Scale = 1e-3));
s.joint('ground', 'link', 'revolute', Name = 'shoulder', Position = 0.3);
s.joint('link', s.couple('tool', @(X) X(:,1) < 0.201), 'fixed');
s.input('tau', 'shoulder');  s.output('th', 'shoulder');

[t, y, x] = s.simulate([0 1], Input = @(t, y) 20*(1 - y.th));
s.animate(t, x);
x0 = s.equilibrium();  sys = s.statespace(x0, Modes = 20);

Installation and Gmsh setup: see README.md in the toolbox folder. The reference manual (model description, analyses, formulation, recipes) is docs/fmbd.md.
