fembd: Finite Elements and Multibody Dynamics

fembd models assemblies of STL parts as multibody systems with rigid and elastic bodies. Elastic parts are meshed with Gmsh; parts are connected by joints, couplings, ties, springs, dampers and transmissions. The same model gives a nonlinear simulation for large motions (with controllers in the loop) and a linear finite-element analysis about a pose (modes, frequency responses, state space, Craig-Bampton reduction).

a = fembd.Assembly();
a.add(fembd.Body.rigidSurface('link.stl', 7850, Scale = 1e-3));
a.add(fembd.Body('tool.stl', fembd.material(70e9, 0.33, 2700), Scale = 1e-3));
a.joint('ground', 'link', 'revolute', Name = 'shoulder');
a.joint('link', a.couple('tool', @(X) X(:,1) < 0.201), 'fixed');
a.input('tau', 'shoulder');  a.output('th', 'shoulder');

m = a.nonlinear(Gravity = [0 0 -9.81]);      % nonlinear simulation
[t, y, x] = m.simulate([0 1], Input = @(t, y) 20*(1 - y.th));
m.animate(t, x);

sys = a.statespace(Modes = 20);              % linear, about the pose

Installation and Gmsh setup: see README.md in the toolbox folder. The reference manual (formulation, API, recipes) is docs/fembd.md.

Modelling and simulation:

  1. Your First Model: a two-link arm with an elastic forearm, simulated with PD control, then analysed linearly
  2. Meshing: meshSTL options, Tet4 vs Tet10, Gmsh GUI meshes, Scale and transform
  3. Materials and Mass: orthotropic materials, mass properties, consistent vs lumped mass
  4. Rigid Bodies: reference dofs, tip masses, RefPoint, mesh-free rigid bodies
  5. Couplings and Joints: joint types, springs, locking, posing, closed loops, belt transmissions
  6. Ties and Interfaces: non-matching meshes, bonded ties, partial bonding, elastic interfaces

Linear analysis about a pose:

  1. Modes: a cantilever against Euler-Bernoulli
  2. Loads and Statics: dofs, supports, loads, gravity, reactions
  3. Dynamics: damping, frequency response, Newmark, state space
  4. Model Reduction: Guyan and Craig-Bampton
